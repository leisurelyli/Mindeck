# Mindeck 产品

[English](product.md) | 中文

## 概述

Mindeck 面向团队内部自部署的 AI（人工智能）协作工作台。开发直接基于公开的 DeepSeek Harness fork，复用其 UI、会话、agent（智能体）执行与插件体系。本文记录产品意图，不是已交付能力清单。

<a id="confirmed-goals"></a>

## 已确定目标

产品方向包含四项相关能力，各项能力在首版中的深度仍需设计。

- 支持复用项目资料的知识库。
- 支持角色与系统指令配置的角色 agent。
- 支持多名真人共享资料、agent、对话与成果的项目。
- 持久保存可复用原始文件和产出文件的文件资源库。

相关术语见[术语表](glossary.zh.md)，实施约束见[架构参考](architecture.zh.md)。

## 范围管理

功能只有经过规格确认并具备可观察的验收条件，才纳入 MVP。提议功能与已确认范围分开记录。任务看板和多人同时编辑文档尚未确认为需求。源码公开不代表业务数据公开，材料存放遵循[文档归属规则](README.zh.md#document-ownership)。

## 开发备注

以下问题用于设计讨论，不构成实施承诺。

- [ ] 选择首版最小且完整的用户流程。
- [ ] 定义项目成员、共享对话参与方式与权限撤销。
- [ ] 定义角色 agent 的配置、复用与编辑权限。
- [ ] 选择支持的知识来源与检索证据要求。
- [ ] 定义文件上传、复用、成果保留与删除行为。
- [ ] 确定部署前提、预期并发与验收证据。

使用[规格模板](templates/spec.zh.md)记录讨论确定的范围、排除项与未解决问题。
